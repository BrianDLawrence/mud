# Security policy

The project is pre-release and does not yet accept production security reports through a dedicated channel. Until a private reporting address is published, do not include exploit details or secrets in a public issue.

Areas requiring particular care include authentication, command replay, MongoDB authorization, player scripting, AI-generated commands, chat abuse, trading, and any future background execution.

Never commit `.env` files, database credentials, auth secrets, private player data, or production exports.
